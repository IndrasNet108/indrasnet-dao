# IndrasNet DAO Core — DevNet Demo

This is a minimal public bundle for reviewing the deployed Solana programs on DevNet.

## What’s Included

- `programs/*/src` — on-chain program source code
- `programs/*/Cargo.toml` — program manifests
- `docs/deployment/program-ids.md` — DevNet program IDs + verification commands
- `docs/deployment/deployment-guide.md` — deployment steps
- `docs/architecture/overview.md` — high‑level architecture summary

## Quick Verification (DevNet)

See `docs/deployment/program-ids.md` for `solana program show` commands and Explorer links.

## Notes

- This bundle intentionally excludes internal archives and heavy reports.
- Tests are present in the source tree but excluded by `publish/.gitignore`.
